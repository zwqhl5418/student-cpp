# 学生成绩管理系统 C++ 后端 — 接口说明文档

> 版本：1.0 | 日期：2026-07-24

## 1. 概述

本系统提供唯一一个 HTTP 接口：成绩查询页面。返回服务端渲染的 HTML 页面，包含班级筛选下拉框和成绩透视表。

---

## 2. 接口清单

| 方法 | 路径 | 说明 |
|:----:|------|------|
| GET | `/` | 成绩查询页面（唯一入口） |
| GET | `/?class=<班级名>` | 按班级筛选成绩 |

---

## 3. 接口详情

### 3.1 GET / — 成绩查询页面

#### 请求

```
GET / HTTP/1.1
Host: localhost:8080
```

##### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:---:|--------|------|
| `class` | string | 否 | (空) | 班级筛选条件。为空时显示全部班级学生 |

#### 响应

##### 成功响应 (HTTP 200)

```
Content-Type: text/html; charset=UTF-8
```

HTML 页面结构：

```
┌─────────────────────────────────────────┐
│  教育成绩数据分析平台 (标题栏)          │
├─────────────────────────────────────────┤
│  班级筛选：[全部班级 ▾] [筛选]          │
├─────────────────────────────────────────┤
│  ┌────────┬──────────┬────┬────┬────┬────┐
│  │ 姓名   │ 班级     │语文│数学│英语│科学│
│  ├────────┼──────────┼────┼────┼────┼────┤
│  │ 张三   │ 一年一班 │ 85 │ 90 │ 78 │ 92 │
│  │ 李四   │ 一年一班 │ 88 │ 76 │ 95 │ 81 │
│  │ 王五   │ 一年二班 │ 92 │ 88 │ 72 │ 85 │
│  │  ...   │ ...      │ .. │ .. │ .. │ .. │
│  └────────┴──────────┴────┴────┴────┴────┘
└─────────────────────────────────────────┘
```

- 班级下拉框通过 `onchange="this.form.submit()"` 自动提交
- 科目列（语文/数学/英语/科学）为固定列
- 无成绩的科目显示 `-`
- 无筛选结果时显示 "暂无成绩数据"

##### 错误响应 (HTTP 500)

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="UTF-8"><title>教育成绩数据分析平台</title></head>
<body>
  <h1>教育成绩数据分析平台</h1>
  <p>数据库连接失败，请检查配置</p>
</body>
</html>
```

#### 请求示例

```bash
# 查询全部学生
curl http://localhost:8080/

# 按班级筛选
curl "http://localhost:8080/?class=%E4%B8%80%E5%B9%B4%E4%B8%80%E7%8F%AD"

# 筛选不存在的班级 → 表格显示 "暂无成绩数据"
curl "http://localhost:8080/?class=不存在的班级"
```

## 4. 数据模型

### 4.1 学生 (Student)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键，自增 |
| name | string | 学生姓名 |
| class | string | 班级名称 |

### 4.2 成绩 (Score)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键，自增 |
| studentId | int | 外键 → students.id |
| subject | string | 科目名称 |
| score | double | 分数，允许 NULL |

### 4.3 透视行 (PivotRow)

| 字段 | 类型 | 说明 |
|------|------|------|
| studentId | int | 学生 ID |
| studentName | string | 学生姓名 |
| className | string | 班级名称 |
| scores | map\<string, double\> | 科目 → 分数映射 |

## 5. 配置项（环境变量）

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `DB_HOST` | `db` | PostgreSQL 主机名 |
| `DB_PORT` | `5432` | PostgreSQL 端口 |
| `DB_NAME` | `student_grades` | 数据库名 |
| `DB_USER` | `student_app` | 数据库用户 |
| `DB_PASSWORD` | `student_pass` | 数据库密码 |
| `HTTP_PORT` | `8080` | HTTP 监听端口（仅 A 方案） |

## 6. A/D 方案差异

### A 方案 (cpp-httplib) 网络路径

```
浏览器 :8080 → cpp-httplib (独立进程，多线程)
```

### D 方案 (FastCGI) 网络路径

```
浏览器 :80 → Nginx → FastCGI (127.0.0.1:9000) → C++ FastCGI 进程
```

接口行为完全一致，差异仅在于：
- A 方案端口可配置（默认 8080）
- D 方案端口由 Nginx 控制，FastCGI 程序通过 Unix Socket 或 TCP 与 Nginx 通信
